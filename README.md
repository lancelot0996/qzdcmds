# 🧵 耗材管家 - 3D打印耗材管理工具

一个轻量级的 3D 打印耗材管理网页应用，无需安装任何环境，打开即用。

## ✨ 功能

- 📦 **耗材库存管理** — 记录品牌、颜色、材质、重量等
- 📅 **开封时间记录** — 记录每卷耗材的开封时间
- 📝 **更换耗材记录** — 记录每次打印消耗，自动扣减库存
- ⚠️ **开封提醒** — 开封过久自动提醒烘干
- 🎨 **多色/多材质分类** — 按材质和状态筛选
- ⚙️ **打印参数记录** — 记录喷嘴温度、热床温度等参数
- 📱 **PWA 支持** — 可添加到手机桌面，像 App 一样使用

## 🚀 如何使用

### 方法一：直接打开（最简单）

1. 找到 `index.html` 文件
2. 用浏览器打开它
3. 就可以开始使用了！

### 方法二：添加到手机桌面（推荐）

如果你想让它像一个真正的 App：

1. 先把文件放到一个可以 HTTPS 访问的地方（比如 GitHub Pages 或手机上的文件服务器）
2. 用手机浏览器打开网址
3. 点击浏览器的"添加到主屏幕"
4. 以后就可以像打开普通 App 一样打开它了

## 📋 数据存储

- 所有数据都保存在你浏览器的本地存储中
- 数据**不会**上传到任何服务器
- 建议定期使用设置页的"导出数据"功能备份

## 🖥️ 技术栈

- 纯 HTML/CSS/JavaScript
- 无需任何框架或依赖
- 支持离线使用（PWA Service Worker）
