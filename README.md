# 🧵 全自动炒面大师 - 3D打印耗材管理工具

一个轻量级的 3D 打印耗材管理应用，打开即用。

## ✨ 功能

- 📦 **耗材库存管理** — 记录品牌、颜色、材质、重量等
- 📅 **开封时间记录** — 记录每卷耗材的开封时间
- 📝 **更换耗材记录** — 记录每次打印消耗，自动扣减库存
- ⚠️ **开封提醒** — 开封过久自动提醒烘干
- 🎨 **多色/多材质分类** — 按材质和状态筛选
- ⚙️ **打印参数记录** — 记录喷嘴温度、热床温度等参数

## 🚀 如何使用
-下载 app文件安装即用
-安装新版本前请导出数据并卸载旧版本防止带来bug

## 📋 数据存储

- 所有数据都保存在你浏览器的本地存储中
- 数据**不会**上传到任何服务器
- 建议定期使用设置页的"导出数据"功能备份
